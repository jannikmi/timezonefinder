## How timezonefinder is referenced

> The code uses the timezonefinder and pytz packages in Python to accurately convert UTC time to local time based on the location of the flash. The timezone_at function from the TimezoneFinder class is used to determine the time zone at each flash location.

Cited as: inline name, with the API call.

## Role of timezonefinder

Converts ISS-LIS lightning-flash times from UTC to local time per flash location, for diurnal analysis of lightning over Canada.
