## How timezonefinder is referenced

> Timezonefinder: librería Python que dadas las coordenadas de latitud y longitud de […] calcula su huso horario correspondiente. • TimeZoneDB: API gratuita previo registro […] Se elige timezonefinder porque no esta expuesto a fallos externos y por tanto la convierte en más fiable.

Cited as: footnote (PyPI URL).

## Role of timezonefinder

Computes the time-zone offset ("desfase horario") between an athlete's home and the competition venue as a performance metric.

## Notes

- The only publication that compares timezonefinder with an alternative. It chooses timezonefinder over the TimeZoneDB web API because working offline makes it independent of external failures.
