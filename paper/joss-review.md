## How the length is counted

JOSS's paper guide gives 750–1750 words as a soft limit that editors apply; papers *significantly* longer may be asked to shorten. The only automated count is the editorial bot's `wordcount` check ([`repo_checks_worker.rb`](https://github.com/openjournals/buffy/blob/main/app/workers/repo_checks_worker.rb), checked 2026-11-19), which is `File.read(paper_path).split.size`: every whitespace-separated token of the raw `paper.md`. That includes the YAML front matter, headings, `[@citekey]` markers, link URLs attached to their text, and HTML comments. Only the reference list, which lives in `paper.bib`, is not counted. Counted locally with `wc -w paper/paper.md`, which gives the same number. (Recorded from #780.)
