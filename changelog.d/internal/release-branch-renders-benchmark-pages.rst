``benchmark.yml`` now renders the published report pages on every push to a ``release/**`` branch, so the artifact a release installs into ``docs/benchmark_results_*.rst`` exists without anybody having remembered to dispatch the job first - nothing started that job before, and skipping it surfaced only at release time as a commit-stamp mismatch. CI still never commits the pages, and a release push renders only: the measurement matrix and the ``gh-pages`` trend chart stay on ``master`` pushes and pull requests. The ``render_reports=true`` dispatch remains for re-rendering an expired artifact and for pull requests outside a release that move a measured path
