the data-report and benchmark-report generators return the RST they produce instead of printing it into a redirected stdout, so the destination is an ordinary argument. ``parse_data`` (``scripts/file_converter.py``) used to rewrite the checkout's committed ``docs/data_report.rst`` whatever ``-out`` it was given, silently leaving it describing someone else's dataset; the report now lands beside the binaries it describes, and only a parse of the packaged data directory writes the committed page. ``python -m scripts.reporting`` gains the matching ``--out``. Both generated report families are byte-identical to what they produced before.
