The converter computes a cell's candidate polygons exactly rather than conservatively. A cell is an axis-aligned rectangle of the stored integer coordinates, so "can this polygon own one of the cell's points" is a planar predicate over two rectangles and a ring, evaluated against the point-in-polygon kernel's own edge convention; ``scripts/hex_utils.py``'s half-turn rotation, polar special cases and three-way overlap tests are gone with the hexagons that needed them, as are the vertex-cell cache and the second copy of every source ring the parse kept for it. ``scripts/audit_shortcut_candidates.py``'s default stream now probes every stored cell's corner integer points, so each grid line is checked from both sides.
