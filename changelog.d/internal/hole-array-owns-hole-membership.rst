``HoleArray`` owns the question "is this point in any hole of boundary polygon *b*": the union bounding box, the ownership lookup and the membership loop are now ``any_contains`` and ``ids_of`` on the array, so ``TimezoneFinder.inside_of_polygon`` no longer knows that a polygon has holes at all. The registry is read before the array is built and handed to it; the parameter is optional because the callers that only read rings - the integrity checks, which construct one in order to *establish* the registry, and the converter's reports - have no ownership question to ask, and an array built without one raises rather than answering.
