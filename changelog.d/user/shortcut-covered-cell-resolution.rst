The shortcut index now answers a cell that one boundary polygon covers entirely with that polygon's zone directly, so the point-in-polygon loop for it disappears: on the 2026c geometry that is 742 of the ambiguous cells, and 2.1-4.4 % fewer polygon tests per query depending on how the points are distributed. Where two zones overlap inside such a cell, precedence now follows a documented containment rule - the zone for which the shared area is the larger share of itself wins - instead of whichever candidate the ordering happened to test first; over the committed fixtures that moves 2 of 5,000 ambiguous points and none of the 20,000 random and on-land ones. It takes effect with the next compiled dataset, since the packaged data is built by the data pipeline rather than by a code release.
