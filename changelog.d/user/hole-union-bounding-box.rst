``TimezoneFinder`` tests a point against one bounding box enclosing all of a boundary polygon's holes before descending into the holes themselves. ``in_any_polygon`` has to visit every hole to establish that the point is in none of them, which is the answer 99.8 % of the time, so the polygon owning 95 holes paid 95 bounding-box tests per point that reached it; one test now answers for the whole set, skipping 75 % of all hole bounding-box tests over the packaged ambiguous fixture. A hole-less polygon carries an empty box, so the majority path no longer builds a ``range`` or consults the hole registry at all. Measured on the ambiguous stratum: -12.5 % minimum, -10.4 % median, 8 of 8 rounds; -4.5 % / -3.0 % on random and on-land points; unique-shortcut points unchanged. The bounds are derived when a finder is constructed, so no data format, binary layout or packaged file changes.
