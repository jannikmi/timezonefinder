``timezones_at()``, as a ``TimezoneFinder`` method and a global function, returns every timezone whose polygons contain a point instead of the single one ``timezone_at()`` has to pick where the dataset's zones genuinely overlap - ``Asia/Urumqi`` inside ``Asia/Shanghai``, and several disputed or dual-administered areas. The list always contains ``timezone_at()``'s answer, which is what stops the two contradicting each other, and that answer is always the first element, so ``zones[0]`` is a drop-in for ``timezone_at()``; the order of the rest is the internal candidate order and carries no meaning. There is no batch form.
