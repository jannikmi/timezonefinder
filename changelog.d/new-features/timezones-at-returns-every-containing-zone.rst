``timezones_at()``, as a ``TimezoneFinder`` method and a global function, returns every timezone whose polygons contain a point instead of the single one ``timezone_at()`` has to pick where the dataset's zones genuinely overlap - ``Asia/Urumqi`` inside ``Asia/Shanghai``, and several disputed or dual-administered areas. Its first element is always ``timezone_at()``'s answer, so the two cannot contradict each other; the order of the rest is the internal candidate order and carries no meaning. There is no batch form.
