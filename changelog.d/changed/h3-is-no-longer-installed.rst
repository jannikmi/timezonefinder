``h3`` is no longer a runtime dependency and is not installed with the package: the grid-tree shortcut index replaced the H3 index it was there for. An ``import h3`` that happened to work because ``timezonefinder`` pulled it in now fails unless ``h3`` is declared directly. Dropping it also removes the one extension in the install that shipped without ``Py_mod_gil``, so on a free-threaded build the GIL now stays disabled.
