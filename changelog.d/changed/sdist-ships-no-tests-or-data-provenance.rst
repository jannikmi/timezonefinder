The source distribution no longer carries ``tests/``, ``DATA_VERSION`` or ``DATA_SOURCE``. The test suite runs from a repository checkout only (it needs ``scripts/``, the bootstrapped dataset and the CI configuration), so the copy in the sdist could not be collected, and the two data files describe the ``timezonefinder-data`` build rather than this package. The sdist shrinks from about 1.3 MB to about 140 KB.
