| Public-contract audit | Comparing runtime docstrings, `:raises:`/`:return:` claims, and callers found drift that syntax checks cannot. Reuse for API changes. |
| Assertion-boundary audit | The AST scan of multi-statement `pytest.raises`/`pytest.warns` blocks found checks whose protected statement was ambiguous. Reuse after broad test rewrites. |

The remaining exclusions are `prototypes/`, `docs/`, and `benchmarks/`; prototypes are excluded deliberately. |
| Packaging-pattern audit | Match every unwanted-distribution pattern against the working tree, then compare it with `MANIFEST.in` and check-manifest ignores. Reuse when repository-only trees or packaging patterns change. |
| Issue and premise revalidation | Check every `GH-<n>` issue state and re-find the code anchor before selection. The issue may close, or unrelated work may invalidate only half the premise; both have occurred. |
| Shortcut coverage sweep | `scripts/hex_utils.py`'s `lies_in_cell` and the three overlap helpers in `scripts/utils_numba.py` were replayed against packaged binaries. Seven resolution-5 child centers across all 288,122 shortcut cells exercise 2,016,842 coordinates. The exhaustive run originally found eight bad answers, including an unsuspected Tuamotus cell; investigation corrected the diagnosis from pole-enclosing cells to antimeridian-straddling cells. After measuring every packaged polygon's longitude span and frame, the clean run found zero answers from cells lacking a containing polygon. `tests/shortcut_test.py`'s `test_the_index_lists_the_polygon_covering_each_sampled_coordinate` is the affordable sampled guard, and the three moved cells were checked against committed benchmark fixtures. |

## Where discovery should start

Start with the [priority ranking](improvement-priority-ranking.md), because known work normally outranks another broad sweep. For fresh discovery, documentation prose is the only broad repository area without systematic coverage; the small explicit delta is a full read of `benchmarks/test_comparison.py`. After those, a filtered Ruff `--select ALL` delta is cheaper than rereading already-covered modules. Always update this map in place and put an actionable finding in its own item file.
