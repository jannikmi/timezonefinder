# PY-1 — Python 3.15 is unclaimed, and 3.12 is past the drop date its floor cites

- **Where:** `requires-python`, the per-minor classifiers and the schedule comment above them in `pyproject.toml`; `envlist` and `[testenv:py312-min]` in `tox.ini`; the `test` matrix, `CIBW_BUILD_VERSIONS` and the end-to-end `uv-python-version` matrix in `.github/workflows/build.yml`; `py_limited_api` in `setup.py`; `requires-python` in `packages/timezonefinder-data/pyproject.toml`. `tests/test_python_version_support.py` holds them to one another, so they move in one change.
- **What is true now:** CPython 3.15.0 was released on 2026-10-09, and the package claims and tests 3.12–3.14 only. The schedule comment above `requires-python` says the earlier of the NEP 29 and SPEC 0 drop dates binds, and that 3.12 reaches it on 2026-10-02. That date has passed, so the comment's own rule says the floor is due to move; NEP 29's date for 3.12 is 2027-04-02.
- **3.15 measures clean.** On macOS arm64 with CPython 3.15.1, the default selection (`-m "not integration and not slow"`) passes in full, with the C extension loaded through the `cp312` abi3 build, both with numba 0.68.0 installed and without it. Put the environment's `bin/` on `PATH` when running it from a scratch venv, or every `tests/cli_test.py` test fails with `FileNotFoundError` for the console script.
- **The lockfile is what a 3.15 leg trips on, not the code.** `uv.lock` holds numba 0.67.0 with llvmlite 0.49.0, and shapely 2.1.2, which the `test` group pulls in through `data`. None of the three publishes a cp315 wheel, and `uv sync --frozen --python 3.15 --group test --group numba` fails building llvmlite 0.49.0 from source. numba 0.68.0, llvmlite 0.50.0 and shapely 2.2.0 publish cp315 wheels, so the leg carries a lock refresh of those three. An install from PyPI is unaffected, because the published bounds already resolve to them, and the locked numpy 2.5.2 and cffi 2.1.1 have cp315 wheels.
- **What keeping 3.12 is worth.** 3.12 was 40.0 % of the package's downloads from 2026-09-21 to 2026-10-20, the largest single minor, against 13.9 % for 3.14 and 9.3 % for 3.13 (`https://pypistats.org/api/packages/timezonefinder/python_minor`). NumPy 2.5.4 and SciPy 1.18.1 both still declare `requires-python >=3.12`, so dropping 3.12 now would put this package ahead of the project whose schedule the comment cites. Dropping it frees no artifact, since the abi3 wheels are one per platform whatever their base.
- **What the change carries.** For 3.15: the classifier, a `py315` tox factor, a `test`-matrix entry, a `cp315` end-to-end leg, and the lock refresh above. If 3.12 goes too: `requires-python >=3.13` in both `pyproject.toml` files, its classifier removed, the abi3 base `cp313` in `setup.py` and `CIBW_BUILD_VERSIONS`, `py312-min` becoming `py313-min` with the NumPy 2.2 floor unchanged until 2026-12-09, ruff `target-version` and mypy `python_version`, the tag `docs/architecture.rst` quotes, and the comment rewritten with 3.13's dates. Either way the fragment goes under `changed/`, per the [changelog policy](../../../development/changelog-and-release-note-policy.md).
- **Decision needed:** which Python window does the next release ship? **(a) 3.12–3.15:** add 3.15 and keep 3.12 until NEP 29's 2027-04-02, rewriting the comment's rule to say the later date binds; it costs one more test-matrix leg until then. **(b) 3.13–3.15:** the comment's rule as written; it moves the abi3 base, and `requires-python` holds the 40 % of downloads on 3.12 at 9.1.x, a step ahead of NumPy and SciPy. **(c) Neither in this release:** ship on 3.12–3.14 and decide later; 3.15 stays unclaimed and outside CI although it measures clean. **Recommendation: (a).** Adding 3.15 is measured and costs a lock refresh. Dropping 3.12 buys only adherence to a date the cited upstream has not acted on yet, and it costs the largest share of installs.
- **Size:** S.
- **Status:** needs a maintainer decision — which Python window the next release ships. Changing the supported versions is outside what an improvement pass may do.
- **Last touched:** 2026-10-22 — recorded by a discovery pass, with 3.15.1 measured and the download shares read.
