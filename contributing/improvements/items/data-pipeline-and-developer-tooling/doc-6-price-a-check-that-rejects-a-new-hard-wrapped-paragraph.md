# DOC-6 — price a check that rejects a newly hard-wrapped paragraph

- **Location:** `.pre-commit-config.yaml`, or `tests/`; the pages [DOC-9](doc-9-migrate-the-documentation-from-sphinx-to-mkdocs.md) converts, plus `README.md`, which is already one line per sentence.
- **What it is.** Those slices buy one clean tree; the convention recorded with the first of them is what is meant to keep it. A check is the cheaper insurance if it can be written without false positives — re-doing the conversion costs far more than the check does.
- **Price it before writing it, and the price is the false-positive rate.** The heuristic is "an unindented prose line whose unindented prose predecessor did not end a sentence" — the one the [documentation source format decisions](../../decisions/documentation-source-format-decisions.md) record, which is already a measuring instrument and not yet a gate. It has to not fire on tables, directives, literal and code blocks, field lists, section underlines, list item starts, or a deliberately broken long link. Measuring that is the work: run the candidate over the converted tree and over `contributing/`, which is already conformant, and count what it flags. A check that fires on correct prose gets `# noqa`-ed into uselessness or disabled, which is worse than no check.
- **This item may legitimately ship no code**, and that is not a failure: if the false-positive rate is not near zero, the outcome is to record the measurement and close this as rejected, keeping the numbers so the next pass does not re-run them. It therefore carries no changelog sentence in advance — a shipped check gets one under `Internal:`, and a refusal gets none.
- **It cannot be taken before DOC-9 has landed**, because it fails on every unconverted page; the README is already converted. That is the only real precondition anywhere in this family, and the whole of its sequencing. The changelog's move to Markdown did not reflow it, so the tail this check skips is the same tail in `CHANGELOG.md`. **The check is also cheaper to write after DOC-9** — it will be reading Markdown rather than reStructuredText, so fences, tables and admonition blocks replace directives, literal blocks, field lists and section underlines in what it has to skip.
- **What the check must skip** is recorded in the [documentation source format decisions](../../decisions/documentation-source-format-decisions.md), alongside the counting method this heuristic comes from: the generated report pages, and `CHANGELOG.md`'s historical tail.
- **Status:** blocked on DOC-9.
- **Last touched:** 2026-09-06 — blockers rewritten onto DOC-9 when the four reflow slices were withdrawn into it, and onto the decisions record when they were consolidated. Sliced out of DOC-1 on 2026-09-05, which raised the check as worth pricing without pricing it.
